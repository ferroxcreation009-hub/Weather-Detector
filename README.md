# Weather Detector 🌤️

A responsive weather app built with HTML, CSS, and JavaScript 
that fetches real-time weather data using the OpenWeatherMap API.

## Features
- Search weather by city name
- Displays temperature, humidity, and wind speed
- Dynamic weather icons based on conditions
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Setup
1. Clone the repo
2. Get a free API key from openweathermap.org
3. Replace `YOUR_API_KEY_HERE` in index.html
4. Open index.html in browser
